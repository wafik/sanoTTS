# Indonesian G2P Switch (issue #2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Phonemize the `indonesian` web voice with indo-g2p instead of espeak-ng, mapping its IPA onto the existing `CP_ID_ID` table so the existing wasm decoder renders it unchanged.

**Architecture:** A new vendored browser bundle (`web/id_g2p.js`, global `SaanoIdG2P`) wraps `indo-g2p/core` (MIT, 235 KB gzipped). A new small script (`web/id_g2p_map.js`, global `SaanoIdMap`) holds a JS copy of the `CP_ID_ID` table (generated from the C header — single source of truth), inserts primary stress, and emits Piper-framed ids `[BOS, PAD, (id, PAD)*, EOS]`. `web/index.html` routes only the `indonesian` voice through it, falling back to the espeak path if the bundle fails to load. No wasm rebuild, no retrain.

**Tech Stack:** Plain JS (IIFE globals, no bundler in browser), Node ≥ 18 for tooling (`node` is available), `npx esbuild` for the one-time vendor step, pytest-free assert-based node checks.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-28-indonesian-g2p-design.md`
- Framing ids are fixed: `BOS=1, PAD=0, EOS=2`; sequence is `1, 0, (id, 0)*, 2` (see `mcu/ports/wasm/snt_g2p_wasm.c`).
- The C header `mcu/ports/wasm/cp_id_tables_multi.h` (`CP_ID_ID[161]`, slot 4) is the source of truth for codepoint→id. Never hand-edit the generated JS table.
- indo-g2p version pinned: `0.1.2` (npm). Must import `indo-g2p/core`, never the root entry (root pulls a 2 MB English table + 3.4 MB POS model).
- Only the `indonesian` voice changes. The other 8 voices and the `mcu` voice keep `snt_g2p_set_voice` untouched.
- No new runtime dependencies anywhere. `indo-g2p` appears only inside the vendored artifact.
- Every output codepoint of `SaanoIdG2P.toPhoneme(text, {english:false})` must exist in the table (verified: the two release sentences + issue words are full coverage; unknown cp → skip + count, never throw).
- Stress rule: insert `ˈ` (U+02C8, id 120) before the penultimate vowel group of each IPA word. Vowel set: `/[aeiouɑɛɪɔəʊ]/`. Monosyllable → stress at word start.

- [ ] **Step 1: Write the generator** `tools/gen_id_cp_table.mjs`:

```js
// gen_id_cp_table.mjs -- extract CP_ID_ID from cp_id_tables_multi.h into a
// browser-loadable JS table. The C header stays the single source of truth;
// never edit web/id_cp_table.js by hand. Re-run after any table change.
//   node tools/gen_id_cp_table.mjs
import { readFileSync, writeFileSync } from "node:fs";
import { fileURLToPath } from "node:url";
import { dirname, resolve } from "node:path";

const here = dirname(fileURLToPath(import.meta.url));
const header = resolve(here, "../mcu/ports/wasm/cp_id_tables_multi.h");
const out = resolve(here, "../web/id_cp_table.js");

const src = readFileSync(header, "utf8");
const m = src.match(/CP_ID_ID\[(\d+)\]\s*=\s*\{([\s\S]*?)\n\};/);
if (!m) throw new Error("CP_ID_ID table not found in " + header);
const entries = [...m[2].matchAll(/\{(0x[0-9a-fA-F]+|\d+)\s*,\s*(\d+)\}/g)]
  .map(x => [parseInt(x[1]), parseInt(x[2])]);
if (entries.length !== parseInt(m[1])) throw new Error(`expected ${m[1]} entries, parsed ${entries.length}`);
const seen = new Set(entries.map(([cp]) => cp));
if (seen.size !== entries.length) throw new Error("duplicate codepoints in CP_ID_ID");

// sanity: the phonemes this whole feature depends on must be present
for (const [cp, want] of [[0x294,109],[0x259,59],[0x25b,61],[0x14b,44],[0x2c8,120]]) {
  const got = entries.find(([c]) => c === cp)?.[1];
  if (got !== want) throw new Error(`cp U+${cp.toString(16)} maps to ${got}, expected ${want}`);
}

const body = entries.map(([cp, id]) => `  {${cp},${id}},`).join("\n");
writeFileSync(out, `\
/* GENERATED by tools/gen_id_cp_table.mjs from mcu/ports/wasm/cp_id_tables_multi.h
 * (CP_ID_ID, slot 4). Do not edit -- re-run the generator instead. */
(function (root) {
  "use strict";
  const MAP = new Map([
${body}
  ]);
  root.SaanoIdTable = Object.freeze({ BOS: 1, PAD: 0, EOS: 2, MAP: MAP });
})(typeof self !== "undefined" ? self : globalThis);
`);
console.log(`wrote ${out}: ${entries.length} codepoints`);
```

```js
/* id_g2p_map.js -- Indonesian front end for the `indonesian` web voice.
 *
 * Indo-g2p emits unmarked IPA; the voice was trained on espeak ids that carry
 * primary stress (ˈ U+02C8). We insert ˈ before the penultimate vowel group of
 * every IPA word (default Indonesian stress), then map each codepoint through
 * the generated CP_ID_ID table and frame Piper-style: BOS, PAD, (id, PAD)*, EOS.
 * Unknown codepoints are skipped and reported, never thrown.
 *
 * Depends on SaanoIdG2P (web/id_g2p.js, indo-g2p core) and SaanoIdTable
 * (web/id_cp_table.js, generated from the C header).
 */
(function (root) {
  "use strict";

  const VOWELS = /[aeiouɑɛɪɔəʊ]/;

  function insertStress(word) {
    // positions where a vowel group starts
    const starts = [];
    for (let i = 0; i < word.length; i++) {
      if (VOWELS.test(word[i]) && (i === 0 || !VOWELS.test(word[i - 1]))) starts.push(i);
    }
    if (!starts.length) return "ˈ" + word;
    const at = starts.length >= 2 ? starts[starts.length - 2] : 0;
    return word.slice(0, at) + "ˈ" + word.slice(at);
  }

  function textToIds(text) {
    const G2P = root.SaanoIdG2P, Table = root.SaanoIdTable;
    const ipa = G2P.toPhoneme(text, { english: false }).phonemes;
    const stressed = ipa.split(/(\s+)/).map(part =>
      /\s/.test(part) ? part : insertStress(part)).join("");
    const ids = [Table.BOS, Table.PAD];
    const skipped = [];
    for (const ch of stressed.normalize("NFD")) {
      const cp = ch.codePointAt(0);
      const id = Table.MAP.get(cp);
      if (id === undefined) { skipped.push({ cp }); continue; }
      ids.push(id, Table.PAD);
    }
    ids.push(Table.EOS);
    return { ids, skipped };
  }

  root.SaanoIdMap = { textToIds };
})(typeof self !== "undefined" ? self : globalThis);
```

```js
// schwa on ~47% of words and never emits glottal stops. SaanoIdMap maps
// indo-g2p IPA onto the same CP_ID_ID ids the voice was trained on. Falls
// back to the espeak path if the bundle fails, so the demo never dies.
let idG2pScripts = null;
function loadIdG2p(){
  if (!idG2pScripts) idG2pScripts = Promise.all([
    loadGlobalScript("id_g2p.js", "SaanoIdG2P"),
    loadGlobalScript("id_cp_table.js", "SaanoIdTable"),
    loadGlobalScript("id_g2p_map.js", "SaanoIdMap"),
  ]);
  return idG2pScripts;
}
async function synthVoiceIndo(text){
  const bundle = await loadVoiceBundle("indonesian");
  let ids, via = "indo-g2p";
  try {
    await loadIdG2p();
    const r = self.SaanoIdMap.textToIds(text);
    if (!r.ids.length || r.skipped.length) throw new Error("unmapped/skip");
    if (r.skipped.length) log("indo-g2p skipped " + r.skipped.length + " codepoints");
    ids = Int32Array.from(r.ids);
  } catch (e) {
    log("indo-g2p unavailable (" + (e && e.message || e) + ") -- using espeak-ng");
    setG2PVoice(bundle.meta.espeak_voice, bundle.meta.g2p_voice_slot);
    ids = g2pIds(text); via = "espeak-ng wasm";
  }
  window.__lastG2pVia = via;
  const frontP = toHeap(Voice, bundle.front), decP = toHeap(Voice, bundle.dec);
  const idsP = toHeap(Voice, new Uint8Array(ids.buffer, 0, ids.length * 4));
  const outP = Voice._malloc(VOICE_OUT_CAP * 4);
  const t0 = performance.now();
  const n = Voice._snt_voice_synthesize(frontP, decP, idsP, ids.length, bundle.meta.length_scale, outP, VOICE_OUT_CAP);
  const wall = (performance.now() - t0) / 1000;
  let pcm = null;
  if (n >= 0) { pcm = new Float32Array(n); pcm.set(Voice.HEAPF32.subarray(outP >> 2, (outP >> 2) + n)); }
  [frontP, decP, idsP, outP].forEach(p => Voice._free(p));
  if (n < 0) throw new Error("snt_voice_synthesize returned " + n);
  return { pcm, ids, wall, sr: bundle.meta.sample_rate || SR };
}
```

```python
    node tools/id_g2p_eval.mjs --dump-ids

import json
from pathlib import Path

import numpy as np

from sanotts.engine import Synthesizer

IDS_JSON = Path("artifacts/id_ids.json")
OUT = Path("artifacts/id_g2p_samples")


def write_wav(path: Path, audio: np.ndarray, sample_rate: int) -> None:
    import wave
    pcm16 = (np.clip(audio, -1.0, 1.0) * 32767.0).astype("<i2")
    with wave.open(str(path), "wb") as h:
        h.setnchannels(1)
        h.setsampwidth(2)
        h.setframerate(sample_rate)
        h.writeframes(pcm16.tobytes())


def frames_to_audio(models, config, ids: list[int]) -> np.ndarray:
    """Run the numpy decoder on a raw (unframed) id sequence."""
    framed = np.array([1, 0] + [x for i in ids for x in (i, 0)] + [2], dtype=np.int64)
    # bypass frontend: acoustic+decoder on the given ids
    durs = models.duration_forward({}, config, framed) if False else None
    raise NotImplementedError  # replaced in-step below


def main() -> None:
    cases = json.loads(IDS_JSON.read_text(encoding="utf-8"))
    OUT.mkdir(parents=True, exist_ok=True)
    synth = Synthesizer("id")  # downloads/caches the id voice
    for n, (text, obj) in enumerate(cases.items(), 1):
        after = synth.synthesize_from_ids(obj["ids"])
        write_wav(OUT / f"{n}-after.wav", after.audio, after.sample_rate)
        before = synth.synthesize(text)
        write_wav(OUT / f"{n}-before.wav", before.audio, before.sample_rate)

    print(f"wrote {OUT}/*.wav")
```
